## SNOW DODGE
hey, this is a fun game that you can play.The concept is inspired by snowglobe.hackcclub.
You are a player name(snowy) and you can move the player left and right in a cerain set speed .The catch is that there is ***snow flakes*** coming from the sky,
You have to dodge the player(snowy) and prevent itfrom touching the snowflakes
The more time you survive the more hard it gets for you to survive in the game
At the end you would get your score as how much time you spend in the game
Press R to restart and Q to quit from snow dodge
BE CAUTIONS!
